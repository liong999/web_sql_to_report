Dynamic Reporting & Excel Export for Odoo 20

Web SQL to Report

Effortlessly generate beautifully formatted, styled Excel (.xlsx) reports directly from raw SQL queries or lists of dictionaries with automatic type detection, formulas, and auto-filters.

Stop Writing Boilerplate Excel Export Code

Building custom Excel reports in Odoo typically requires dozens of lines of repetitive styling and sheet formatting. Web SQL to Report abstracts all the heavy lifting into a single, elegant Python API call. Just pass your SQL query dictionary results or data list, and receive a fully formatted, auto-columned, formula-calculated XLSX workbook ready for instant download.

Key Highlights & Features

Powerful reporting utility built natively for Odoo 20 developers

Direct SQL Query Result Support

Feeds directly from cr.dictfetchall() or any Python list of dictionaries without manual transformation.

Auto Cell Formatting

Automatically detects data types (Float, Integer, Date, DateTime) and applies formatted alignments and number masks.

Smart Column Widths

Calculates maximum text and header length per column automatically so data is never truncated or squeezed.

Autofilter & Freeze Panes

Applies interactive Excel autofilters and locks header/column freeze panes for seamless large dataset navigation.

Dynamic Formula Totals

Automatically writes SUM or customized formulas at the footer row for numeric fields without manual coordinate math.

Multi-Sheet & Header Summaries

Create multi-tab workbooks via data_sheet and inject custom KPI summary headers with specific cell references (e.g. A1, B2).

Quick Start Developer Example

Trigger an Excel report download from any Odoo model in just 4 lines of code

def action_print_partner_report(self):
    # 1. Execute SQL query
    query = """
        SELECT name, phone, email, credit_limit, create_date 
        FROM res_partner 
        WHERE customer_rank > 0 
        LIMIT 50
    """
    self.env.cr.execute(query)
    report_data = self.env.cr.dictfetchall()

    # Option A: Quick & Minimal (Standard Excel Export)
    return self.env['web.report'].generate_report(
        report_name='Customer Report',
        data=report_data,
    )

    # Option B: Advanced Customization (Header Styling, Dates & Summary Footers)

generate_report() Parameters

Full list of customization parameters available

Parameter Type Default Description
report_name str Required File prefix and sheet name
data list[dict] Required List of dictionaries representing rows and headers
data_sheet dict False Dictionary of sheet names to data lists for multi-tab workbooks
start_date / end_date str / date False Adds formatted report title header with date range
header_color str (HEX) '#FFFACD' Hex background color for column headers and totals
numbering bool True Adds an incremental row number ("No") column at index 0
auto_filter bool True Enables Excel filter dropdowns on the header row
freeze_panes bool True Freezes header row and specified leading columns
show_total_footer bool True Appends formula sum row at the bottom for numeric columns
